# ESP32 Firmware for Biometric Contact Recognition

This directory contains the firmware source code for the ESP32 microcontroller paired with AS608 / R307 optical fingerprint modules.

- `esp32/fingerprint_controller/`: Arduino C++ code supporting serial & WiFi communication.
- Pinouts, baud rate configurations, and biometric command protocols are detailed in [docs/hardware.md](../../docs/hardware.md).
